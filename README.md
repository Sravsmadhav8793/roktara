# Roktara Business Prototype

Mobile-first, clickable prototype for a B2B fraud-intelligence product serving fintechs, banks, payment teams and enterprise finance operations.

## Run

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Prototype scope

- WhatsApp and Telegram bot simulation for explicitly forwarded content
- Forward-only default, optional Android notification-preview mode, separate evidence-sharing consent and revoke flow
- Link, UPI QR, message, screenshot and attachment/APK check flows
- Explainable sample risk, low-signal and uncertain-review results
- Call Guard for family-video deepfake emergencies and Customs/CBI/ED digital-arrest impersonation
- Family verification-code workflow, independent verification checklist, ED website route and 1930/cybercrime reporting
- Case creation, search, filters, assignment context and resolution
- Sample campaign network and downloadable intelligence brief
- Notifications, alert policy controls, team invitations and API request preview
- CSV, JSON and text exports
- Installable PWA shell with mobile safe-area support

All data and assessments are illustrative and generated locally. The prototype does not perform live fraud detection, OCR, QR decoding, malware analysis, WhatsApp/Telegram delivery, API integration, authentication or server-side persistence. It must not be used for payment decisions.

The application uses React, TypeScript, Vite and Lucide icons. No external visual assets are required.
